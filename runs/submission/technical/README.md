# Техническая проверка КТ3 — 23 ноября 2026

Это fixtures, не ручной B0 и не научная оценка Qwen. Расход модели 0 RUB;
токены синтетические. Реальные источники, поиск и публичные dev-входы сохранены.

- `fixture-dev.zip: verified-baseline/`, `fixture-dev.zip: verified-system/`: один общий runner, шесть dev-заданий
  в каждом варианте. В каждой папке задания — вход, настройки, события,
  результат, корпус и manifest с хешами кода/данных/промптов.
- `scenarios.json`: S1–S6, фактические события Runtime и протокол проверок.
- `*-fixture-resources.json`: длительности локального кода; научные метрики null.
- `checks.json`: результат чистой установки и тестов.

Повтор проверок: `./run.sh check` и `./run.sh scenarios --output runs/local/scenarios.json`.
Новый session-id нужен для каждого нового запуска. Измеренное время зависит
от компьютера; точное совпадение длительностей не требуется. Параметры, порядок
данных и логика проверок воспроизводимы. API/ключи/private gold не использовались.

Актуальные результаты реального system и статус ручного B0:
[страница сдачи](../../../docs/SUBMISSION.md). Эти артефакты нельзя переименовать
в реальный baseline или подтверждение качества модели.
